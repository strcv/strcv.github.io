# Личный сайт

Личная страница. Astro, статика, TypeScript. Публикуется на GitHub Pages из этого же
репозитория. С рабочими проектами не пересекается: здесь только личное.

## Правила

- Перед любой правкой вёрстки или стилей читай `docs/design.md`. Токены —
  `docs/design-tokens.md`, чек-лист перед сдачей — `docs/design-review.md`.
- Цвета, отступы, размеры шрифта — только переменные из `src/styles/global.css`.
  Сырых значений (`#3b3b3b`, `padding: 13px`) в компонентах быть не должно.
  Нужно новое значение — сначала добавь его в шкалу в `:root`.
- Личные данные (имя, био, ссылки, блок «Сейчас») живут только в
  `src/site.config.ts`. Не дублируй их в разметке.
- Клиентский JS добавляем только если без него нельзя. Сейчас его ровно
  столько, сколько нужно переключателю темы.
- Новая заметка или проект — это новый `.md` в `src/content/`, а не правка кода.
- Стили компонента живут в его же `.astro` в теге `<style>`. Глобальным делаем
  только то, что действительно общее.
- `site` в `astro.config.mjs` — адрес публикации. Из него собираются канонические
  ссылки и `sitemap.xml`, поэтому меняется только вместе с реальным переездом сайта.

## Проверка перед коммитом

```bash
pnpm typecheck
pnpm build
```

Их же гоняет публикация: красный прогон означает, что сайт не выложится.
