# Личный сайт

Личная страница. Astro, статика, TypeScript. Публикуется на GitHub Pages из этого же
репозитория. С рабочими проектами не пересекается: здесь только личное.

## Правила

- Перед любой правкой вёрстки или стилей читай `docs/design.md`. Токены —
  `docs/design-tokens.md`, чек-лист перед сдачей — `docs/design-review.md`.
- Цвета, отступы, размеры шрифта — только переменные из `src/styles/global.css`.
  Сырых значений (`#3b3b3b`, `padding: 13px`) в компонентах быть не должно.
  Нужно новое значение — сначала добавь его в шкалу в `:root`.
- Личные данные (имя, био, ссылки, блок «Сейчас») живут только в
  `src/site.config.ts`. Не дублируй их в разметке.
- Клиентский JS добавляем только если без него нельзя. Сейчас он есть только
  у поиска и фильтра в списке `/watch-later/`.
- Новая заметка или проект — это новый `.md` в `src/content/`, а не правка кода.
- Стили компонента живут в его же `.astro` в теге `<style>`. Глобальным делаем
  только то, что действительно общее.
- `site` в `astro.config.mjs` — адрес публикации. Из него собираются канонические
  ссылки и `sitemap.xml`, поэтому меняется только вместе с реальным переездом сайта.

## Раздел Watch Later (/watch-later/)

- Данные — `src/content/videos/<slug>.json`, файл на ролик. Имя файла и есть адрес
  разбора `/watch-later/<slug>/`. Схема — коллекция `videos` в `src/content.config.ts`.
- Записи создаёт внешняя автоматизация, конвейер описан в `docs/watch-later/README.md`.
  Формат записи — контракт с ней: поменял схему — поменяй и конвейер. Схема строгая:
  лишнее, пустое или битое поле роняет `pnpm build`, и сайт не выложится.
- Список тегов закрытый — `TAGS` в `src/content.config.ts`. Расширяется только правкой
  схемы. Запись не проходит по тегу — значит, либо дописать тег в схему, либо чинить
  конвейер; ослаблять проверку ради зелёной сборки нельзя.
- Транскрипты — `public/watch-later/transcripts/<slug>.md`, отдаются как есть. В записи поле
  `transcript` хранит путь `/watch-later/transcripts/<slug>.md`.
- Раздел только на русском, и это не временно: английских страниц и пункта «Видео»
  в английской версии нет и не будет. Страницы передают в `Base` `translated={false}`:
  переключателя языка в шапке нет, hreflang не ставится, в sitemap — только русский адрес.
- Пункт «Видео» в шапке задан в `nav.menu` в `src/i18n/ru.ts`; в `en.ts` меню пустое.

## Проверка перед коммитом

```bash
pnpm typecheck
pnpm build
```

Их же гоняет публикация: красный прогон означает, что сайт не выложится.
