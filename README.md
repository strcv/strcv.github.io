# Личный сайт Александра Старцева

Astro, TypeScript, статическая сборка. Русская и английская главные, три парных кейса,
русский раздел Watch Later. Адрес: https://strcv.github.io/.

## Работа с сайтом

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm build
pnpm check:site
pnpm preview
```

Нужны Node 22+ и pnpm 10.33.0. Проверка собранных страниц использует Python 3
(стандартная библиотека, без дополнительных пакетов).

| Содержание | Файл |
| --- | --- |
| Контакты и адреса CV/портфолио | `src/site.config.ts` |
| Тексты главной RU/EN | `src/i18n/ru.ts`, `src/i18n/en.ts` |
| Кейсы | `src/content/cases/{ru,en}/<slug>.md` |
| Превью кейсов | `cases.items` в словарях |
| Видео | `src/content/videos/<slug>.json` |
| Транскрипты | `public/watch-later/transcripts/<slug>.md` |
| Цвета, размеры, отступы | `src/styles/global.css` |

Ссылки без адреса не показываются посетителям. Неподтверждённые сведения и вопросы
к владельцу фиксируются в `docs/audit-2026-09-29.md`, а не в опубликованной странице.
Порядок десяти разделов, принципы работы и позиционирование сохранены из `docs/tz.md`.
Дизайн: `docs/design.md`; проверка: `docs/design-review.md`.

Watch Later только на русском, без переключателя языка. Пустая очередь — допустимое
состояние. Интеграция с внешним конвейером описана в `docs/watch-later/README.md`.

## Проверки и публикация

Pull request запускает `.github/workflows/check.yml`: типы, сборка, проверка ссылок,
якорей, ресурсов, метаданных, языковых пар, sitemap и отсутствия редакционных заглушек.
Пуш в `main` запускает `.github/workflows/deploy.yml` с теми же проверками и публикацией
на GitHub Pages. Сам pull request сайт не публикует.

GitHub Pages использует корневой `404.html` для неизвестных адресов, в том числе
под `/en/`. На нём есть переключатель на английскую страницу `/en/404/`.
Обе страницы исключены из sitemap и помечены `noindex`.
