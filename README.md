# Личный сайт

Статический сайт на Astro: визитка, проекты, заметки. Клиентского JS — только
переключатель темы.

Живёт по адресу **https://strcv.github.io/** — публикуется из этого же
репозитория, автоматически при каждом пуше в `main`.

## Запуск

```bash
pnpm install
pnpm dev         # http://localhost:4321, перезагружается на лету
pnpm build       # статика в dist/
pnpm typecheck   # проверка типов
```

## Что править

| Что | Где |
| --- | --- |
| Имя, био, ссылки, блок «Сейчас» | `src/site.config.ts` |
| Цвета, шрифты, отступы | `src/styles/global.css` — только переменные в `:root` |
| Адрес сайта | `site` в `astro.config.mjs` |
| Новая заметка | новый `.md` в `src/content/blog/` |
| Новый проект | новый `.md` в `src/content/projects/` |

### Заметка

```md
---
title: Заголовок
description: Одно предложение — оно же в списках и в RSS.
date: 2026-09-01
tags: ['разработка']
draft: false
---

Текст.
```

`draft: true` — файл не попадёт ни в список, ни в RSS, ни в сборку.

### Проект

```md
---
title: Название
summary: Одно предложение о сути.
role: Что делал
year: '2026'
stack: ['TypeScript', 'Postgres']
url: https://example.com      # необязательно
repo: https://github.com/...  # необязательно
order: 1                      # меньше — выше в списке
---
```

## Публикация

Пуш в `main` → [workflow](.github/workflows/deploy.yml) ставит зависимости,
проверяет типы, собирает и выкладывает `dist/` на GitHub Pages. Токенов и
секретов заводить не нужно: публикация идёт штатными действиями GitHub.

Свой домен подключается в Settings → Pages → Custom domain, после чего меняется
`site` в `astro.config.mjs` — из него собираются канонические ссылки и
`sitemap.xml`.
