# Чек-лист ревью страницы

Проходить по порядку. Каждый пункт — либо «да», либо конкретная правка.
Формулировка вида «как-то не смотрится» правкой не считается.

## Содержание и иерархия

- [ ] На первом экране понятно, что это и зачем, без прокрутки.
- [ ] Ровно один главный призыв к действию. Второстепенные визуально тише.
- [ ] Заголовки образуют осмысленное оглавление, если читать только их.
- [ ] Нет текста-заглушки и нет «lorem ipsum» в том, что уходит наружу.

## Типографика

- [ ] Длина строки в абзацах 60–75 символов (`max-width: 66ch`).
- [ ] Размеры взяты из шкалы; произвольных значений нет.
- [ ] Интерлиньяж у заголовков меньше, чем у текста (1.1–1.25 против 1.6).
- [ ] На кегле от 24px стоит отрицательный трекинг.
- [ ] Начертаний не больше двух.
- [ ] Числа в таблицах выровнены по правому краю и моноширинные
      (`font-variant-numeric: tabular-nums`).

## Цвет

- [ ] Одна нейтральная шкала и один акцент. Дополнительные цвета — только
      семантика.
- [ ] Все цвета — переменные; сырых значений в компонентах нет.
- [ ] Контраст текста 4.5:1, крупного 3:1. Проверено, а не на глаз.
- [ ] Смысл нигде не передаётся одним лишь цветом.
- [ ] Тёмная тема не является инверсией: фон не `#000`, текст не `#fff`, акцент
      осветлён.

## Сетка и пространство

- [ ] Отступы взяты из шкалы 4/8/12/16/24/32/48/64/96.
- [ ] Расстояния задаёт родитель (`gap`), а не внешние `margin` компонентов.
- [ ] Между секциями воздуха больше, чем внутри секции.
- [ ] Элементы одного уровня выровнены по одной линии.
- [ ] Радиусы согласованы: вложенный элемент имеет радиус меньше родительского.

## Состояния

- [ ] hover, focus-visible, active, disabled описаны у всех интерактивных
      элементов.
- [ ] Кольцо фокуса видно и не убрано через `outline: none`.
- [ ] Есть состояние загрузки — и оно не прыгает по высоте
      (скелет вместо спиннера там, где известен размер).
- [ ] Есть пустое состояние: что показать и что предложить сделать.
- [ ] Есть состояние ошибки: что случилось и что делать дальше.

## Доступность

- [ ] Кнопки — `<button>`, ссылки — `<a href>`.
- [ ] Всё достижимо с клавиатуры, порядок табуляции совпадает с визуальным.
- [ ] Иконки без подписи имеют `aria-label`, декоративные — `aria-hidden`.
- [ ] У картинок осмысленный `alt`, у декоративных — `alt=""`.
- [ ] Цель нажатия минимум 44×44px на тач-устройствах.
- [ ] `lang` у `<html>` стоит правильный.

## Движение

- [ ] Микровзаимодействия 120–200ms, крупные переходы 250–400ms.
- [ ] Анимируются только `transform` и `opacity`.
- [ ] `prefers-reduced-motion` уважается.
- [ ] Каждая анимация что-то объясняет; декоративных нет.

## Адаптив

- [ ] Проверено на 375px, 768px, 1440px.
- [ ] Горизонтальной прокрутки страницы нет ни на одной ширине.
- [ ] Широкое содержимое (таблицы, код, диаграммы) прокручивается внутри своего
      контейнера, а не растягивает страницу.
- [ ] Текст читается без зума на телефоне (минимум 16px в полях ввода — иначе
      iOS зумит форму).

## Техника

- [ ] Картинки сжаты, заданы `width`/`height` — макет не прыгает при загрузке.
- [ ] Шрифты подгружаются с `font-display: swap` или взяты системные.
- [ ] `<title>` и `description` уникальны на каждой странице.
- [ ] Есть OG-теги: страница нормально выглядит ссылкой в мессенджере.
- [ ] Ссылки наружу с `rel="noopener"`.
- [ ] Страница 404 существует и ведёт обратно.
