# Скил `video-recap`

Вход: метаданные ролика (`yt-dlp --dump-json`) и текст субтитров с тайм-метками.
Выход: один JSON-объект по схеме из `README.md` плюс готовый текст поста для Telegram.

## Промпт

Ты делаешь карточку для каталога Watch Later. Задача каталога — дать человеку понять,
что внутри ролика, чтобы он сам решил, смотреть ли его целиком. Оценки «стоит / не стоит»
не давай никогда: ни в заголовке, ни в выводах, ни в описании.

Правила:

- `title` — русский заголовок о содержании, а не перевод оригинального. Без кликбейта,
  без вопросительных заголовков, без «вы не поверите». До 70 знаков.
- `summary` — одна-две фразы: о чём ролик и с какой стороны автор заходит. До 220 знаков.
- `takeaways` — 3–5 законченных утверждений, которые человек уносит, не открывая видео.
  Каждое должно быть проверяемым тезисом с конкретикой, а не заголовком раздела.
  Плохо: «Автор говорит о ценообразовании». Хорошо: «Оплата за место ломается,
  когда продукт заменяет работу, а не помогает её делать».
- `timecodes` — 3–6 меток на смысловые переходы. Ставь только те, к которым захочется
  перемотать. Если в описании ролика уже есть главы — бери их, переведя и отфильтровав.
- `tags` — ровно один или два из закрытого списка: AI, агенты, разработка, продукт,
  стартапы, деньги, интервью, туториал. Ничего своего не придумывай.
- Если в субтитрах бессвязица или это не про технологии — верни `{"skip": true, "why": "..."}`.

Отвечай только JSON, без markdown-обёртки и без пояснений.

## Пост в Telegram

Отдельным полем `tg_text`. Лимит подписи к картинке — 1024 знака, держись в 700.

```
<b>{title}</b>
{channel} · {duration}

{summary}

{для каждого takeaway: «— » и текст}

<a href="{url}">Смотреть</a> · <a href="{site}/watch-later/{slug}/">Тайм-коды и транскрипт</a>
#{тег1} #{тег2}
```

Для подборки из 3–4 роликов — другой шаблон: заголовок темы, дальше по каждому ролику
жирное название, длительность, одна строка summary и ссылка на разбор. Выводы в подборку
не идут, они остаются на сайте.
